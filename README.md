# داشبورد شخصی — چارت ماهانه‌ی عملکرد

همون نمودار کاغذی ماهانه، این بار به شکل یک اپلیکیشن وب: هر روز تسک‌هات رو ثبت و تیک می‌زنی،
و نموداری از تعداد تسک‌های انجام‌شده‌ی هر روز ساخته می‌شه که نقطه‌هاش به هم وصل شدن.

**استک:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · SQLite لوکال یا Postgres ابری
**تقویم:** شمسی (پیش‌فرض) با امکان سوییچ به میلادی · رابط کاربری کاملاً راست‌چین · فونت وزیرمتن (لوکال، بدون CDN)

---

## راه‌اندازی سریع

```bash
npm install
npm run dev
```

بعد برو به <http://localhost:3000>. همین. دیتابیس SQLite خودش در `data/shenskho.db` ساخته می‌شه
و جدول‌ها خودکار مایگریت می‌شن — نه Prisma لازمه، نه مایگریشن دستی.

### داده‌ی نمونه (اختیاری)

برای اینکه نمودار رو با داده‌ی واقعی‌نما ببینی:

```bash
npm run dev          # در یک ترمینال
node scripts/seed-demo.mjs   # در ترمینال دیگر
```

برای پاک کردن همه‌چیز: `rm -f data/shenskho.db*`

## سوییچ به دیتابیس ابری

اپ با یک متغیر محیطی بین SQLite لوکال و Postgres ابری جابه‌جا می‌شه — هیچ کد دیگه‌ای تغییر نمی‌کنه.

۱. یک دیتابیس رایگان بساز روی [Neon](https://neon.tech) یا [Supabase](https://supabase.com).
۲. فایل `.env.example` رو به `.env.local` کپی کن و این خط رو بذار:

```env
DATABASE_URL=postgresql://user:pass@host/dbname?sslmode=require
```

۳. `npm run dev` — همین. جدول‌ها خودکار در Postgres ساخته می‌شن.

بعد از این، همون دیتا از موبایل هم قابل دسترسیه (اگر اپ رو روی Vercel هم دیپلوی کنی).

### دیپلوی روی Vercel

```bash
npx vercel
```

در تنظیمات پروژه در Vercel، `DATABASE_URL` رو با آدرس Postgres ست کن.
(روی Vercel حتماً باید Postgres باشه، چون فایل‌سیستم اونجا موقتیه و SQLite پاک می‌شه.)

## قفل ورود با رمز (اختیاری، پیشنهادی برای دیپلوی روی اینترنت)

اگر اپ رو روی Vercel دیپلوی می‌کنی و می‌خوای فقط خودت بهش دسترسی داشته باشی، یک متغیر محیطی ست کن:

```env
APP_PASSWORD=یک-رمز-قوی-اینجا
```

با این کار همه‌ی صفحات پشت یک صفحه‌ی ورود ساده قرار می‌گیرن (بدون حساب کاربری، فقط یک رمز مشترک).
اگر این متغیر رو ست نکنی، قفل کلاً غیرفعاله — برای اجرای لوکال روی کامپیوتر خودت لازم نیست.

## دستیار هوشمند (چت)

صفحه‌ی **دستیار هوشمند** (`/chat`) یک چت فارسی است که مستقیماً داده‌ی اپ را مدیریت می‌کند:
مثلاً «فردا جلسه با مشتری و ورزش رو اضافه کن»، «روتین مطالعه برای شنبه تا چهارشنبه بساز»، «هدف روزانه رو بذار ۵ تا».

- فقط یک کلید رایگان لازم است (`GEMINI_API_KEY` یا `GROQ_API_KEY` یا `OPENROUTER_API_KEY`؛ راهنما در `راهنمای-API-های-رایگان-AI.md`). اگر چند کلید باشد، با تمام شدن سقف یکی خودکار سراغ بعدی می‌رود.
- مدل با **tool-calling** ابزارهای `src/lib/assistant/tools.ts` را صدا می‌زند (تسک، روتین، پروژه، دسته، هدف، یادداشت روز، خلاصه‌ی هفته). برای قابلیت جدید فقط یک ابزار به همین فایل اضافه کن.
- **حذف‌ها هیچ‌وقت خودکار انجام نمی‌شوند**؛ دستیار یک کارت تأیید نشان می‌دهد و فقط با زدن «تأیید حذف» اجرا می‌شود (`/api/assistant/confirm`).

## نصب به عنوان اپ (PWA)

اپ یک Progressive Web App هست — از مرورگر موبایل یا دسکتاپ گزینه‌ی «Add to Home Screen» /
«نصب اپ» رو بزن تا مثل یک اپ مستقل (بدون نوار آدرس) باز بشه و حتی آفلاین هم صفحه‌ی اصلی رو نشون بده.

│  ├─ weekly/page.tsx       مرور هفتگی و تمرکز هفته‌ی بعد

└─ lib/
   ├─ ai/chat.ts            گفتگوی ابزارمحور با Gemini / Groq / OpenRouter

   ├─ date/jalali.ts        تبدیل شمسی↔میلادی (بدون وابستگی)

## چند نکته‌ی طراحی

- **تاریخ‌ها همیشه به صورت میلادی ISO (`YYYY-MM-DD`) ذخیره می‌شن** و فقط موقع نمایش به شمسی تبدیل می‌شن.
  این یعنی سوییچ تقویم هیچ داده‌ای رو نمی‌شکنه و مرتب‌سازی/کوئری‌ها ساده می‌مونن.
- **روتین‌ها تنبل (lazy) ساخته می‌شن:** اولین باری که وارد یک روز می‌شی، تسک‌های روتین‌های فعال اون روز ساخته می‌شن.
  اگر یکی رو پاک کنی، دیگه برنمی‌گرده (جدول `routine_days` این رو نگه می‌داره).
- **پالت رنگ نمودار از نظر کوررنگی (CVD) تست‌شده‌ست** و برای تم روشن و تیره دو مجموعه‌ی جدا داره.
- **بدون localStorage برای داده‌ی اصلی** — فقط تم و انتخاب تقویم اونجا ذخیره می‌شن.
